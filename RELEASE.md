# v0.1.0-beta.1 — Native EinsatzPulse-Alarm-App
Native Kotlin/Compose-Android-App, Release-Kandidat auf dem gemergten main.
Android GitHub Actions: Unit Tests, Lint und assembleDebug; veröffentlichte APK ist debugsigniert.
Firebase Messaging erfordert installationsbezogene Client-/Server-Credentials.
Nicht als offizielle bzw. garantiert zugestellte Feuerwehr-Alarmierung verwenden.
